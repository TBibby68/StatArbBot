# Excel Figure Creation

Whenever creating or adding a figure/chart to an Excel workbook:

1. Keep the presentation sheet clean and suitable for inclusion in the research paper.
2. Put any helper calculations, cumulative series, intermediate formulas,
   or transformed data required for the figure on a separate worksheet.
3. Name that worksheet "Figure Calculations" unless an appropriate calculation
   sheet already exists.
4. Hide the calculation worksheet after creating the figure.
5. The visible worksheet should contain only the final results/data intended
   for inspection and the finished figure.
6. Do not replace source data or formulas with hard-coded values merely to
   simplify the chart.
7. Never modify the underlying backtest results when creating a figure.
